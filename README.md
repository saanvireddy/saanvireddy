## 👩‍💻 About Me

I'm an **AI Engineer with 4 years of Python engineering experience across healthcare, payments, and banking**, focused on building Generative AI applications and intelligent backend systems.

My work spans **Retrieval-Augmented Generation (RAG), agentic AI workflows, LLM evaluation, fine-tuning, and API development**.
